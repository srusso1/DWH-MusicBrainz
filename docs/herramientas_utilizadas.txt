1. MOTOR DE BASE DE DATOS Y GESTIÓN DE ALMACENAMIENTO ANALÍTICO
--------------------------------------------------------------------------------
- PostgreSQL 16 (Imagen Oficial Docker `postgres:16`):
  * Motor relacional y gestor de almacenamiento para el Data Warehouse analítico.
  * ¿Por qué se utilizó PostgreSQL 16?
    - Soporte maduro y de alto desempeño para Particionamiento Declarativo por Rangos
      (Range Partitioning), permitiendo Partition Pruning en consultas masivas.
    - Soporte nativo para COPY streaming ultrarrápido desde flujos en memoria (STDIN),
      alcanzando tasas sostenidas superiores a 150.000 filas por segundo.
    - Manejo eficiente de Vistas Materializadas con índices únicos que habilitan
      su refresco concurrente o periódico (`REFRESH MATERIALIZED VIEW`).
    - Tipos de datos nativos de alta precisión: `UUID` para identificadores únicos
      globales (MBID), `TIMESTAMPTZ` para auditoría temporal con huso horario,
      `BIGINT` para métricas acumuladas y `TEXT` sin penalización para cadenas extensas.
    - Motor de costos optimizado con Workers Paralelos (`max_parallel_workers`, 
      `max_parallel_maintenance_workers`) y soporte de Dynamic Shared Memory (`posix`).
  * Configuración y Tuning de Rendimiento en PostgreSQL:
    - `shared_buffers = 1GB`: Buffer pool ampliado para cachear páginas de datos e índices.
    - `maintenance_work_mem = 1GB`: Memoria dedicada para creación de índices B-Tree y VACUUM.
    - `work_mem = 64MB`: Memoria asignada por operación para Hash Joins y ordenamientos.
    - `max_wal_size = 8GB`: Margen holgado para amortiguar checkpoints durante ingestas masivas.
    - `checkpoint_completion_target = 0.9`: Suavizado de operaciones de escritura I/O en disco.
    - `shm_size = 1gb` (Docker): Memoria compartida asignada al contenedor para evitar errores
      de Dynamic Shared Memory al procesar agrupaciones masivas sobre 19M de registros.

2. INFRAESTRUCTURA, VIRTUALIZACIÓN Y AISLAMIENTO
--------------------------------------------------------------------------------
- Docker & Docker Compose v2:
  * Despliegue reproducibilidad y portabilidad total del entorno empresarial sin ensuciar
    el sistema operativo anfitrión.
  * Puerto aislado `5435:5432` para evitar colisiones con instancias locales de PostgreSQL.
  * Volumen nombrado persistente `mb_pgdata` con retención de datos entre recreaciones.
- PowerShell 7 / Windows Terminal:
  * Entorno de scripting y ejecución CLI para automatización de tareas y monitoreo.

3. LENGUAJE Y ENTORNO DE DESARROLLO (ORQUESTACIÓN ETL)
--------------------------------------------------------------------------------
- Python 3.12+ (Entorno Virtual Aislado `.venv`):
  * Lenguaje líder en Ingeniería de Datos para la orquestación del flujo E2E.
  * ¿Por qué se eligió Python sin frameworks pesados (Spark, Airflow)?
    - Principio de Simplicidad y Cero Sobrecarga (KISS / Solid Foundations):
      Un pipeline directo con streaming en Python + `psycopg2` aprovecha el motor de
      PostgreSQL nativo sin la latencia ni el consumo de recursos de una JVM distribuida.
    - Control granular del flujo de memoria mediante la clase `MaxLineReader`, que
      implementa streaming con buffer de 128 KB para cargar exactamente 15.000.000 de pistas
      sin saturar la memoria RAM del host.
- uv / venv:
  * Gestor de dependencias ultrarrápido y aislamiento de paquetes de Python.

4. LIBRERÍAS Y DEPENDENCIAS DE PYTHON (requirements.txt)
--------------------------------------------------------------------------------
- psycopg2-binary:
  * Driver PostgreSQL nativo escrito en C. Provee acceso de bajo nivel a la API libpq,
    habilitando `copy_expert` para streaming directo a través del protocolo COPY binario/texto.
- python-dotenv:
  * Carga automática de variables de entorno desde `.env` para garantizar seguridad y
    cero credenciales quemadas en el código fuente (Twelve-Factor App).
- reportlab (v5.0+):
  * Motor de composición y maquetación de PDFs programáticos de estándar editorial.
    Permite construir el documento de sustentación técnica con diseño responsive,
    tablas profesionales con estilo, cajas de código y numeración dinámica de dos pasadas.
